# PetOS

**PetOS** is a multi-agent AI software-engineering operating system where autonomous, specialist AI pets visually perform real development tasks inside an interactive pixel-art office. 

## Features
- **Visual Development:** Watch your AI team collaborate in a real-time pixel-art office.
- **Autonomous Agents:** Meet Captain, ThemeFox, and BugDog. Each brings their own specialty to the table.
- **Secure Execution:** A sandboxed environment allows agents to safely write code, run tests, and execute terminal commands.
- **GitHub Integrated:** Seamlessly pull issues, clone repositories, and create Pull Requests.
